### Procedure

### A. Controlled generation

Script: `generate_ddim_pilot.py`.

1. Check that all requested checkpoint files exist and model configurations agree.
2. Create one shared initial-noise bank with fixed sample IDs.
3. Load each selected checkpoint and generate completed images from that bank.
4. Save individual PNGs, raw final tensors, preview grids and metadata.
5. Independently reload and repeat the first condition to test exact reproducibility.

For example, `sample_00000` starts from the same noise in every model/checkpoint.
This controls the input so differences can be studied without changing the
initial noise assignment.

The script rejects duplicate weight files or identical loaded model states across
different conditions. It also records hashes for provenance. These are safeguards
against accidentally comparing the same model twice, not proof of independent
training histories.

### B. Fourier representation

Script: `analyze_fft_mantel.py`.

For each individual generated PNG:

1. Convert RGB values to floating-point values in [0, 1].
2. Convert to grayscale: `0.299 R + 0.587 G + 0.114 B`.
3. Subtract the image's mean brightness.
4. Compute a 2D FFT with orthonormal normalization; set the DC component to zero.
5. Calculate power as `abs(FFT) ** 2`.
6. Flatten `log1p(power)` into a feature vector.

The default run uses no Hann window, radial averaging or frequency-band selection.
No per-image normalization of the resulting spectra is applied.

**What this represents:** frequency power describes the strength of spatial
variations at different scales. It is not a semantic image representation.
Grayscale leaves out color differences, and power leaves out phase. PNG clipping
and quantization are part of the specified preprocessing.

### C. Distance matrices and Mantel tests

Within each model/checkpoint condition, calculate Euclidean distances between
every pair of Fourier feature vectors. This produces one **16 × 16 matrix**.

Its rows and columns represent the shared noise sample IDs—not Fourier bins.

Mantel correlation asks whether two conditions have similar patterns of
image-to-image distances. For example, if samples 1 and 2 are close in model A,
are they also close in model B?

| Test setting | Value |
|---|---|
| Correlation | Pearson |
| Alternative | Two-sided |
| Permutations | 9,999 |
| Permutation seed | 20261013 |
| Permutation unit | Image labels, jointly permuting rows and columns |
| Multiple comparisons | Holm adjustment over all valid planned comparisons in the run
