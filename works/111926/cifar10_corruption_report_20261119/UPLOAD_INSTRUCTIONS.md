# Upload this report to GitHub

Upload `REPORT.md`, the complete `figures/` folder, and the complete `evidence/` folder into the same repository directory, for example `works/11192026/`.

```text
works/11192026/
  REPORT.md
  figures/
    by_corruption/   (15 PNGs)
    by_image/        (10 PNGs)
  evidence/         (4 JSON/CSV files)
```

Open `REPORT.md` on GitHub after committing. Its relative links work regardless of the parent folder name, provided this internal layout is preserved. Upload the extracted contents, not just the ZIP or Markdown text. The report and its assets require 30 files; this instruction file is optional.

All 25 panels are included. Three appear directly in the main text, twelve are in expandable sections, and ten per-image panels are linked in a table. Full-resolution PNGs can be opened separately.

Keep your existing full pilot folder locally: this smaller upload package does not duplicate the 750 individual corrupted PNGs. It does preserve the original metadata files unchanged.
